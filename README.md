# 🎓 QuizApp AI Pro (v1.2)

> **Интеллектуальная образовательная платформа:** генератор тестов на базе ИИ, интерактивный курс Python, терминал Skulpt, 3D-карточки Flashcards V2, кабинет преподавателя, 6 дикторов и поддержка любых локальных / облачных нейросетей.

---

## 🌟 Ключевые возможности

### 1. 🤖 Поддержка любых нейросетей (Локальные + Облачные)
- **⭐ Рекомендация автора: Qwen 3.5 (9 млрд параметров / `qwen3.5:9b`)**
  - **Идеальный баланс скорости и ума:** моментально генерирует тесты на современных GPU (RTX 3060, 4060, 5070 и выше).
  - **Вшитый алгоритм «Анти-Бред»:** специально подобранный эталонный системный промпт исключает галлюцинации и лишний текст, выдавая строгий валидный JSON.
  - **Авто-установка в 1 клик:** просто запустите `Установить_ИИ_Qwen_3.5.bat` или выполните `ollama run qwen3.5:9b`.
- **Локальный ИИ (100% бесплатно и оффлайн):**
  - Поддержка **Ollama** (`qwen3.5:9b`, `qwen2.5:14b`, `deepseek-r1`, `llama3`, `mistral`).
  - Возможность указать любой кастомный IP/порт (удалённый сервер или локальная сеть).
- **Облачные API:**
  - **Groq Cloud** (сверхбыстрый бесплатный запуск LLaMA 3.3 / LLaMA 3.1 со скоростью до 300 токенов/сек).
  - **OpenRouter** (доступ ко всем мировым моделям).
  - **OpenAI / LM Studio / Custom OpenAI-compatible Endpoints**.

### 2. 🎙️ 6 Уникальных дикторов озвучки (TTS)
- 🌟 **Google Студийный (Онлайн)** — естественный, мягкий студийный женский голос.
- 🌸 **Алиса (Офлайн)** — нежный звонкий тембр.
- 👨‍🏫 **Профессор (Офлайн)** — глубокий мужской баритон (академический стиль).
- ⚡ **Наставник (Офлайн)** — энергичный и бодрый темп речи.
- 🌙 **Спокойный чтец (Офлайн)** — размеренная аудиокнига для релакса.
- 🤖 **Windows Стандарт** — классический голос без модуляции.
- Ползунки скорости, высоты тона и очистка текста от технических символов и кода.

### 3. 🐍 Встроенный курс Python + Терминал (Offline)
- **18 интерактивных уроков** от основ до продвинутого уровня:
  - Переменные, типы данных, условия, циклы `for`/`while`
  - Списки, словари `dict`, методы строк, функции
  - Обработка исключений `try/except`, работа с файлами
  - ООП (классы и объекты), List Comprehension, Lambda, генераторы `yield` и декораторы
- **Независимый терминал Python 3 (Skulpt):**
  - Запуск произвольного кода прямо в браузере без установки Python
  - Поддержка горячих клавиш (Ctrl+Enter, Tab-отступы), копирование вывода, подсказки по ошибкам

### 4. 🃏 Умные 3D-карточки (Flashcards V2)
- 4 готовых обучающих набора (Python, Литература, Физика, История)
- 3D-анимация переворота и навигация клавиатурой (Space / стрелки)
- Режим шпаргалки (быстрый список всех терминов с поиском)
- Генератор карточек с помощью ИИ на любую тему
- Возможность добавлять и сохранять свои собственные карточки

### 5. 👩‍🏫 Кабинет преподавателя
- Генерация контрольных и самостоятельных работ
- Разделение на варианты (Вариант 1, Вариант 2)
- Готовые критерии оценивания и ключ правильных ответов
- Оптимизированная печать на листах **А4** прямо из браузера

### 6. 🎮 Геймификация и профиль
- Система уровней, XP и наград
- Статистика правильных ответов и времени
- Банк ошибок для повторения сложных вопросов
- Звуковые эффекты и современные неоновые темы оформления

## 🚀 Быстрый запуск

### Вариант 1: Запуск приложения в Windows (Портативный режим)
1. Дважды кликните по файлу **`Запустить_QuizApp.bat`** (или откройте `index.html` в любом браузере).
2. Приложение запустится в режиме отдельного чистого окна.

### Вариант 2: Онлайн-версия без установки (GitHub Pages)
Приложение доступно прямо в браузере:  
👉 **[https://zazutkin.github.io/QuizApp/](https://zazutkin.github.io/QuizApp/)**

### Вариант 3: Подключение рекомендуемого локального ИИ
1. Запустите **`Установить_ИИ_Qwen_3.5.bat`**.
2. Скрипт проверит/установит Ollama и загрузит рекомендованную модель `qwen3.5:9b`.
3. При генерации тестов приложение автоматически будет использовать вашу локальную видеокарту на полную мощность!

## 🛠️ Технологический стек
- **Frontend:** Vanilla JS (ES6+), HTML5 Canvas, CSS Grid/Flexbox, LocalStorage API
- **Audio Engine:** Google Cloud TTS Audio Stream + Web SpeechSynthesis API
- **Python Engine:** Skulpt 1.2 (in-browser Python runtime)
- **AI Integrations:** Ollama REST API, OpenAI API v1, Groq Cloud API, OpenRouter API
- **Zero Dependencies:** Приложение работает автономно без Node.js-сборщиков
