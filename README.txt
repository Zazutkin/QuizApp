1. 🚀 БЫСТРЫЙ СТАРТ
---------------------------------------------------------------------------
1. Дважды кликни по «Запустить_QuizApp.bat».
2. Приложение откроется как отдельная программа Windows.
3. СРАЗУ РАБОТАЕТ БЕЗ ИНТЕРНЕТА (100% ОФФЛАЙН):
   • 🐍 Интерактивный курс Python (18 уроков с практикой).
   • 🖥️ Python-терминал — пиши и запускай код прямо в окне программы.
   • 🎴 Умные 3D Карточки (Flashcards V2) — Python, Литература, Физика,
     История, режим шпаргалки и создание своих карточек.
   • 👩‍🏫 Кабинет преподавателя (печать готовых вариантов на А4).
   • 📊 Профиль, опыт (XP), темы оформления и банк ошибок.

---------------------------------------------------------------------------
2. 🧠 ПОДКЛЮЧЕНИЕ НЕЙРОСЕТИ (НА ТВОЙ ВЫБОР!)
---------------------------------------------------------------------------
В версии v1.2 добавлена полная свобода подключения ИИ:

ВАРИАНТ А: ЛОКАЛЬНО НА СВОЕЙ ВИДЕОКАРТЕ (OLLAMA / RTX 5070 / ЛЮБАЯ GPU)
• Запусти файл «Установить_ИИ_Qwen_3.5.bat» (он сам всё скачает в 1 клик).
• Либо введи в консоли: ollama run qwen3.5:9b
• Поддерживаются ЛЮБЫЕ кастомные модели и хосты: во вкладке «Настройки»
  можно ввести любой IP/порт и любую модель (DeepSeek, LLaMA, Mistral).

ВАРИАНТ Б: БЕСПЛАТНЫЙ ОБЛАЧНЫЙ API (GROQ / OPENROUTER / OPENAI)
• Если не хочешь греть видеокарту или качать 7 ГБ:
  1. Зайди во вкладку «⚙️ Настройки» в приложении.
  2. Выбери «🌐 Облачный API».
  3. Кликни на кнопку «⚡ Groq» (или OpenRouter / DeepSeek).
  4. Вставь бесплатный ключ и нажми «⚡ Проверить подключение».
• Скорость генерации через Groq: до 300 токенов в секунду даже на слабом ПК!

ВАРИАНТ В: LM STUDIO / LLAMA.CPP / VLLM
• Поддерживается любой локальный OpenAI-совместимый сервер (localhost:1234/v1).
